# Atmosphere // Minimal Weather Tracker

A sleek, human-designed web dashboard built to demonstrate clean frontend architecture and live API data fetching.

# Core Features
* **Dynamic Search:** Instantly fetches live, real-time global weather conditions.
* **Modern UI:** Built with a fully responsive, custom dark-mode interface optimized for readability.
* **Asynchronous Logic:** Handles network requests gracefully without forcing manual browser refreshes.

# Tech Stack & Skills Shown
* **HTML5:** Semantic structure and document layout.
* **Modern CSS:** Custom properties (variables), Flexbox alignment, and modern dark-mode aesthetics.
* **JavaScript (ES6):** Asynchronous programming using `async/await`, the `fetch` API, error catching, and dynamic DOM manipulation.

# How It Works
The script captures the user's input string, validates it, and pings an external JSON weather payload. It parses the resulting temperature, weather descriptions, and humidity metrics, rendering them immediately into a custom UI card component.
